# MemePad Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Бесплатная звуковая панель для Windows: по глобальной горячей клавише звук смешивается с голосом и уходит в VB-Audio Cable, который в Discord и играх выбран как микрофон.

**Architecture:** Два проекта. `MemePad.Core` — чистая логика без Windows API: модели, настройки, горячие клавиши, микшер, эффекты, кольцевой буфер, логика PTT. Она покрыта модульными тестами. `MemePad.App` — WPF-приложение: обвязка NAudio/WASAPI, хук клавиатуры и мыши, SendInput, TTS, окно в стиле варианта A, трей. Аудиопоток: WasapiCapture(микрофон) → эффекты → Mixer(+звуки) → WasapiOut(CABLE Input); отдельный WasapiOut(наушники) получает только звуки.

**Tech Stack:** C# 13, .NET 10 (LTS), WPF, NAudio 2.2.x, NAudio.Vorbis, CommunityToolkit.Mvvm, H.NotifyIcon.Wpf, System.Speech, xUnit — все бесплатны (MIT/Apache).

**Spec:** `docs/superpowers/specs/2026-10-16-memepad-design.md`. Утверждённый дизайн окна — вариант A «Список» на холсте https://claude.ai/artifact/A3qDss2FSJX5A6aU86RZMT.

## Global Constraints

- Windows 10 1809+ и Windows 11, x64; `net10.0` (Core), `net10.0-windows` (App, тесты аудио).
- Всё бесплатно; лицензия проекта MIT. Зависимости только под MIT, Apache-2.0 или BSD. Никакой телеметрии и никаких сетевых запросов, кроме открытия ссылки VB-Audio по клику.
- Код полностью уникален относительно Soundpad/UniteFx: ни их имён (`UniteFx*`, `sp_remote_control`, `DoPlaySound`, `R-200`), ни форматов (`.spl`), ни звуков, переводов, иконок и структур памяти. Свои имена классов и ключей JSON.
- Звук в микрофон — только через устройство вывода VB-Cable «CABLE Input». Драйвер не распространяется, только ссылка https://vb-audio.com/Cable/.
- Данные: `%APPDATA%\MemePad\settings.json`, клипы в `%APPDATA%\MemePad\Recordings`. Звуки хранятся ссылками на исходные файлы.
- Не делаем: автозапуск, управление извне (сеть, pipe, Stream Deck), APO и драйверы, macOS и Linux.
- Задержка от клавиши до звука в кабеле — до ~100 мс: буфер вывода ~20 мс, звуки предекодированы в память.
- Интерфейс RU и EN, по умолчанию язык системы. Окно — вариант A, тёмный: фон `#121316`, линии `#23252b`, поверхность `#1b1d22`, чип клавиши `#1f2127` с рамкой `#2c2f36`, текст `#e9eaee`, приглушённый `#8a8d97`, акцент `#7c9cff`, подвал `#15161a`, звезда избранного `#f2b94b`, скругления 8–10 px. Шрифты (решение Claude, системные): Segoe UI Variable / Segoe UI, для клавиш Cascadia Mono / Consolas.

## Review Focus

1. **Битый или пропавший файл звука:** строка помечается («файл не найден» или «не удалось прочитать»), остальные звуки играют, программа не падает. Тест в Task 7.
2. **Отключили микрофон, гарнитуру или кабель во время работы:** движок переподключается к устройству по умолчанию или ждёт возврата и не падает; статус в подвале меняется. Тест в Task 7 (переподключение через фейковый перечислитель).
3. **Одна и та же клавиша назначена дважды** на одной странице: диалог назначения предупреждает и предлагает переназначить; на разных страницах это допустимо. Тест в Task 3.
4. **Быстрые многократные нажатия:** не больше 16 одновременных голосов, повтор той же клавиши перезапускает звук, а не копит копии. Тест в Task 4.
5. **Много звуков плюс громкий микрофон:** выход всегда в [-1, 1] без цифрового клиппинга (мягкий лимитер). Тест в Task 4.
